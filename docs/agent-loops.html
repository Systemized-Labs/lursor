The Agent
Loop Taxonomy

Twenty ways to keep a coding agent running for days without a human. They look like twenty different things. They are one machine with five moving parts, and each family jams a different part.

Every loop is an answer to two questions: what decides what happens next, and what decides that it's done.

Pick your loop by what you can actually measure — not by what sounds sophisticated
01 Anatomy

One cycle, five stations

Strip away the names and every loop below runs the same circuit. What separates a Ralph loop from a Gauntlet loop is not structure — it's which station gets all the engineering. Hover a family to see which one it specializes.

Notice what never lights up. COMMIT — checkpoint on green, revert on red — is the one station every loop needs and no family innovates on. It's also the station that decides whether a bad hour costs you an hour or costs you the run. Build it first; it's the cheapest reliability you will ever buy.

03 The central tradeoff

Cheap or discerning. Not both.

04 What actually predicts endurance

Fresh context beats clever

The loops that survive unattended for days are not the sophisticated ones. They are the ones that throw the context away and re-derive state from disk each unit of work. Compaction is lossy, and over hundreds of turns the loss compounds into goal drift.

05 Failure

Every loop is gamed by its own yardstick

A loop's failure mode is never random. It is precisely the selection pressure you installed, turned back on you. Whatever you measure is what gets faked — which is the whole argument for stacking loops with orthogonal failure modes instead of endlessly tuning one.

06 Prescription

Layer three, on three clocks

No single loop covers scaffolding and correctness and taste. Take one from Ledger for cheap coverage, one from Judgment for quality, one from Reality for ground truth — and run them on different timescales so drift in the fast loop gets caught by the slow one.

You are the brake — so build one. Every pattern here runs forever by construction; that's the feature and the bill. With nobody watching you need a hard dollar ceiling, a wall-clock cap, plateau detection (K rounds with no verdict movement), and auto-revert on a red gate. And borrow the Darwin‑Gödel archive: keep the branches that lost. A run that grinds for forty hours is usually a run that discarded the variant that would have worked.
